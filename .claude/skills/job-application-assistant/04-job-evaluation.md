# Job Fit Evaluation Framework

## Skill Match Areas
- **Strong match:** .NET Core, C#, Web API, Microservices architecture, SQL Server, PostgreSQL, RESTful integrations, Azure DevOps, CI/CD.
- **Moderate match:** Front-end frameworks (Angular, React, JavaScript), NestJS, Node.js, Kafka, Blazor.
- **Weak match:** Mobile app development natively (Swift, Kotlin), heavy Data Science/Python engineering (as primary role).

## Language Gate
Required Language: English. Any role demanding native fluency in another language (e.g., German, French, Danish) is an automatic mismatch.

## Salary & Commute Baseline
- **Location:** Strictly Remote or Worldwide remote openings (time overlaps with Indian Standard Time context if applicable, or globally asynchronous).
- **Target Postings:** Needs to prioritize roles posted within the last 12 hours.

## Calibration from Past Applications
- Roles such as ".NET Backend Engineer", "Full-Stack .NET Developer", and "Software Engineer (.NET/Azure)" are the sweet spot. 
- Positions explicitly looking to leverage modern AI tools (Cursor, Copilot) are highly desired.

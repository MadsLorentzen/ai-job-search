# 国内社招规则

本 fork 默认面向中国大陆社招。以下规则优先于原国际模板中的语言、固定页数、求职信、电话联系和渠道默认值；事实核对、岗位正文完整性、审查和 PDF 验证继续保留。用户明确申请海外岗位时采用原流程。所有路径以仓库根目录解析。

## 建档与个人信息

默认用简体中文交流、输出简历，保留 Java、SQL、CRM 等通用技术或业务术语。`/setup` 继续支持导入简历或访谈；先确认再记录个人事实，不从当前打开的公司代码推断履历。

补充以下社招信息到 `01-candidate-profile.md` 的「国内社招偏好」，`CLAUDE.md` 仅保留市场和语言指针：目标岗位/职级、当前及意向城市、可接受通勤/搬迁、真实工作年限、在职/离职与到岗时间、目标行业、劳动合同主体偏好（直签/外包/派遣）、工作时间和出差偏好。未知填「待确认」，不能自动设为拒绝条件。

薪资可选：分别记录期望税前月薪、保证发薪月数、税前年现金目标、奖金/提成是否保证、股权是否单列。当前薪资不是必填，不主动写进对外简历。只收集用户自愿提供的工作所需信息；简历默认不放身份证号、详细住址、婚育、照片、年龄和第三方联系人。

## 搜索与岗位获取

优先企业招聘官网、BOSS直聘、猎聘、智联招聘、前程无忧、用户确认的内推渠道。平台主页与来源：

- BOSS直聘：https://www.zhipin.com/
- 猎聘：https://www.liepin.com/
- 智联招聘：https://www.zhaopin.com/
- 前程无忧：https://www.51job.com/

当前国内支持方式是 **WebSearch 发现线索 + 公开正文验证 + 用户粘贴 JD 导入**，没有这些平台的自动登录或私有 API 适配器。工具 `tools/china_jobs.py search-plan` 只生成搜索词，不联网。搜索摘要不足以评分，不把搜索日期当职位发布时间。岗位未知发布时间、工作地点、薪资或直签主体时明确标注。

遇到登录、验证码或权限墙，转企业官网或请用户粘贴完整 JD，不索取账户密码/cookie，不循环重试登录。人工导入先经过 posting_guard；告警需要展示原始发现并征求是否继续。`review_required` 是待审标记，不是拒绝岗位的依据。

`/scrape` 在国内模式只运行国内 WebSearch 和人工导入路径，不运行海外 CLI。保留其去重、状态保存和结果展示规则。LinkedIn/freehire 以及丹麦示例保留供用户明确选择国际市场；国内模式不生成 LinkedIn 人脉搜索链接，不默认建议打电话，优先给平台沟通、招聘邮箱或内推消息草稿。

## 匹配与薪资

沿用 `04-job-evaluation.md` 四个维度及权重，分数用于排序，不表示录用概率。国内模式额外展示：岗位/职级、经验要求、学历要求、城市/通勤、薪资结构、用工形式、工作时间、到岗时间；每项给「匹配 / 不匹配 / 待确认」及正文依据。只有用户明确的硬约束才触发 veto，不从学校层次、年龄或照片推断能力。

学历和年限按实际资料核对；相邻经验可解释，不篡改入职时间、毕业时间或管理范围。工作时间、社保公积金、试用期、绩效和外包主体未写明时生成向 HR 确认的问题，不推断公司一定有或没有该条件。法律与税务问题单独查证，不把招聘文案当法律结论。

运行 `python3 tools/china_jobs.py salary '20-30K·13薪'` 做口径拆分。工具输出的是 **JD 标注范围的算术换算**，不是市场薪资统计、税后收入或保证收入。例：20-30K·13薪的名义年薪是26万-39万元；未标发薪月数则不推断年薪。年包、奖金、提成、股票与日薪单独处理，只有同口径才能比较。

## 简历、沟通和面试

国内申请采用 `.claude/commands/apply-cn.md`，生成中文单栏 A4 简历和 `outreach.md` 沟通草稿。简历通常1-2页，内容少可以1页，不为凑页数加内容；资深经历超过2页时先裁剪相关度低的内容，再由用户决定是否保留扩展版。英文职位或外企明确要求英文时遵循用户选择。

社招优先顺序：个人优势 → 工作经历 → 核心项目 → 技能 → 教育；非技术岗位按岗位需要更换项目/技能章节。正文强调业务问题、个人职责、具体行动、真实结果。没有数据就描述可验证效果，团队成绩写明个人参与部分。不要把 AI 工具或 Claude Code 品牌自动加入简历。

沟通草稿包含：80-150字平台招呼、150-250字自我介绍、3个与 JD 有关的确认问题；只使用已确认事实，不在占位符未补齐时声称可直接发送。只有用户或雇主明确要求时生成正式求职信。所有消息只起草，发送需用户明确授权。

面试优先准备岗位要求、真实项目追问、个人贡献、选型与取舍、离职动机、期望薪资/到岗时间和反问；技术岗位再补技术原理与系统设计。准备30秒/2分钟自我介绍，不虚构生产事故或量化收益。空窗、转岗和缺项用真实解释，不包装成不存在的工作。

## 状态与隐私

继续使用原 `job_search_tracker.csv` 状态词（`drafted`、`applied` 等）及原表头，不把生成材料当成已经投递。正式求职信缺省时 `cover_letter_file` 留空；沟通稿放同一申请归档目录。`/outcome` 只归档实际存在/提交的材料，不为填列虚构文件。Notion/Gmail/HTML 报表读取时允许此列为空。

`/setup` 会修改已跟踪的个人档案；本仓库仍是公开 fork，个性化资料只留本地或另存私有库，改 `.gitignore` 无法隐藏已跟踪文件。当前配置改动不包含个人资料，不自动提交、推送、投递或发送消息。

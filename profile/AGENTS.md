# Profile — the candidate factory

Stable facts and policies, read (never rewritten) on every run. `methods/setup.md`
populates these; facts only change through it or an approved correction.

| File | Holds |
| --- | --- |
| `profile.md` | Identity, education, experience, skills — the grounding source |
| `01-candidate-profile.md` | Extended profile the apply workflow audits against |
| `02-behavioral-profile.md` | Working style, team fit |
| `03-writing-style.md` | Voice for cover letters and emails |
| `04-job-evaluation.md` | Fit policy: language gate, deal-breakers, scoring |
| `09-web-research.md` | How to research employers |

Rule: an ungrounded claim anywhere in an application traces back here or it
does not ship. Facts discovered mid-conversation get recorded here in the same
turn (see `methods/03-apply.md` grounding audit).

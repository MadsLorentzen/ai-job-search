# Portfolio learning projects

These three briefs are provisional learning options, not findings from actual job
applications. No target postings have been imported into this workspace yet. No
project implementation, demonstrated proficiency, or measured result is claimed.

| Track | Project | Skills to demonstrate | Planning budget |
|---|---|---|---|
| Data Engineering | [Fleet analytics warehouse](fleet-analytics/PROJECT.md) | dbt, incremental models, data tests | 18-26 hours |
| AI Engineering | [Evidence-grounded diagnostic assistant](diagnostic-assistant/PROJECT.md) | retrieval evaluation, citations, abstention | 22-32 hours |
| Data Science | [Battery model validation benchmark](battery-validation/PROJECT.md) | grouped temporal evaluation, uncertainty, error analysis | 18-28 hours |

Use `/learn-project <job URL>` to select/adapt one after comparing the actual posting
against the private profile. If a skill is already well demonstrated, choose a harder
extension or skip the lab. Suggested initial order: fleet analytics for a DE target,
diagnostic assistant for AI, or validation benchmark for DS. Do not start all three.

Each lab is a build brief with milestones. Implement one milestone, commit your work,
and explain the decision before asking the assistant to review it. Completion means
reproducible evidence and understanding, not simply code produced by an agent.

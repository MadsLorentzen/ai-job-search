Agentic AI Engineer - Full remote - Europe


Our SaaS client based in The Netherlands are in need of a number of AI Engineers who can design, build and deploy agentic systems to their customers.


This is a hands-on engineering role, focused on turning ideas into fast POCs and then scaling them into production-ready systems.


What you’ll be doing:

  • Designing and building agentic & multi-agent systems
  • Developing high-performance APIs that power AI agents at scale
  • Improving agent performance, responsiveness and reliability
  • Collaborating closely with Product to deliver quick POCs and iterate fast
  • Deploying AI systems into production using the Azure ecosystem
  • Making smart technical trade-offs and clearly explaining them to stakeholders


Tech environment:

  • Python / Kotlin
  • Azure (DevOps, backend services, AI services)
  • API-driven architectures
  • Agentic / multi-agent systems
  • Scalable backend & cloud deployments


What we’re looking for:

  • Strong experience as an AI Engineer / Backend Engineer
  • Proven work with agentic or multi-agent systems
  • Solid API development experience at scale
  • Comfortable deploying and operating systems in Azure
  • Able to explain how agents perform, scale and improve particularly with technical and non-technical stakeholders
  • Someone who can deliver fast POCs and think long-term


Location : Fully remote (Europe)

Duration : 3-month rolling contract

Headcount : 2

Rate : €375 - 400 a day

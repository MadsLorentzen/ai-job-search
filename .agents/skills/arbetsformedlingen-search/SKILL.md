# Arbetsförmedlingen (Platsbanken) Search Skill

Search live Swedish job listings via Sweden's official **JobSearch API**
(`jobsearch.api.jobtechdev.se`), the public open-data platform that backs the
Platsbanken board at arbetsformedlingen.se. No authentication, no API key, and
**zero runtime dependencies** — it runs with just `bun`.

> Country-specific portal skill, generated by `/add-portal` for Jan-Torben's Sweden-market
> job search. Per repo policy this lives in the fork rather than being merged upstream.

## Public open-data API — keep volume reasonable

This is Sweden's official public-sector job-search API, built for reuse (not a scrape of
pages that weren't meant for automated access). Still, run it at a reasonable pace: a
search or two plus a handful of `detail` lookups per session, not a bulk crawl. No
rate-limit headers were observed during testing, but the CLI backs off on 429/5xx anyway.

## When to use this skill

- Search for job openings anywhere in Sweden, in any sector
- Filter by recency (posted in the last N days) or sort newest-first
- Get the full description of a specific job listing (deadline, employer, apply link)

## Commands

### Search job listings

```bash
bun run .agents/skills/arbetsformedlingen-search/cli/src/cli.ts search [flags]
```

Key flags:
- `--query <text>` / `-q <text>` — free-text keywords (title, skill, role). **There is no
  `--location` flag** — the API extracts location from free text itself, so include a city
  in the query to narrow by location, e.g. `-q "ingenjör Jönköping"` (see Notes).
- `--jobage <days>` — posted within N days (maps to the API's `published-after`). Omit for all postings.
- `--sort <mode>` — `relevance` (default) or `date` (newest first).
- `--page <n>` — page number (1-indexed).
- `--limit <n>` / `-n <n>` — results per page / cap. Default 20, API max 100.
- `--format json|table|plain` — default `json`.

### Fetch full job detail

```bash
bun run .agents/skills/arbetsformedlingen-search/cli/src/cli.ts detail <id|url> [--format json|plain]
```

`id` is the numeric ad ID from `search` results (e.g. `31322464`). You may also pass a
full `arbetsformedlingen.se/platsbanken/annonser/<id>` URL. Returns the full description,
employer, employment type, working hours, deadline, and apply link.

## Usage examples

```bash
# Research engineer roles, last 14 days
bun run .agents/skills/arbetsformedlingen-search/cli/src/cli.ts search -q "forskningsingenjör" --jobage 14 --format table

# Robotics engineer roles in Gothenburg, newest first
bun run .agents/skills/arbetsformedlingen-search/cli/src/cli.ts search -q "robotikingenjör Göteborg" --sort date --format table

# Hydrographic survey roles, all postings
bun run .agents/skills/arbetsformedlingen-search/cli/src/cli.ts search -q "hydrograf" --format table

# Autonomous systems roles in Jönköping
bun run .agents/skills/arbetsformedlingen-search/cli/src/cli.ts search -q "autonoma system Jönköping" --format json

# Full details for a specific job
bun run .agents/skills/arbetsformedlingen-search/cli/src/cli.ts detail 31322464 --format plain
```

## Output formats

| Format | Best for |
|--------|----------|
| `json` | Default — programmatic use, passing IDs to `detail` |
| `table` | Quick human-readable scanning |
| `plain` | Reading a single job's full detail (`detail` command) |

All errors are written to **stderr** as `{ "error": "...", "code": "..." }` and the process exits with code `1`.

## Notes

- Data is from Sweden's official JobSearch API (jobtechdev.se) — no credentials required, results are the same ads shown on arbetsformedlingen.se/platsbanken.
- **Location is free-text, not a filter parameter.** Plain-text `municipality=<name>` params were tested and silently returned zero results (the API expects an internal taxonomy ID there, not a city name) — instead, put the city in `--query` and the API's own NLP concept extraction filters by it correctly (confirmed live during setup: `q="ingenjör Jönköping"` returned only Jönköping results).
- `--jobage` filters by `published-after`; there's no equivalent "posted today" shortcut, use `--jobage 1`.
- Descriptions come back as clean plain text already (`description.text`) — no HTML stripping needed, unlike LinkedIn/Jobindex.
- Ad IDs are numeric (e.g. `31322464`) — pass them as-is to `detail`.
- See `url-reference.md` for the full endpoint/parameter reference and quirks found during setup.

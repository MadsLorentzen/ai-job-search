# RSS / Atom feeds

There is no single host. Each `--feed` URL is a standard RSS 2.0 or Atom document.

Parsed tags:

- RSS: `item` / `title` / `link` / `pubDate` / `description` / `guid`
- Atom: `entry` / `title` / `link href` / `updated` or `published` / `summary` or `content`

Query and recency filters are client-side.

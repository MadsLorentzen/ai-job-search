# 待开发与待验证清单

**更新时间：** 2026-09-02  
**依据：** 当前代码、[国内平台开发台账](./domestic-platform-development-plan.md)、[后续开发路线图](./next-development-roadmap.md)  
**说明：** “已接入”仅表示代码入口存在；只有完成真实流程、失败场景和安全验收后，才可标记为“已完成”。

## 1. 当前结论

项目已经具备“国内职位统一字段 + 智联只读 + 猎聘只读包装 + BOSS/51job 人工导入 + 本地 Web 控制台 + OpenAI 兼容 AI 匹配”的开发基础，但距离普通用户可完整使用，还缺三类工作：

1. **真实环境验收**：候选人资料、智联、猎聘、BOSS/51job、OpenAI 服务尚未完成完整联调。
2. **Web 编排闭环**：搜索、AI 排名、任务进度、结果筛选和本地历史已完成首版，仍需真实服务验收和重启恢复。
3. **产品化增强**：浏览器辅助、申请跟踪、安装包和新手可用性测试仍未完成；PDF/Word 与输入产品化已完成首版。

## 4. P2：后续产品能力

| 编号 | 事项 | 范围 |
|---|---|---|
| P2-01 | 浏览器辅助导入 | 用户明确选择当前 BOSS/51job 页面后读取正文；遇到登录、验证或 CAPTCHA 立即中止，不自动提交 |
| P2-02 | 申请材料工作台 | 复用 `/apply` 生成定制简历/求职信草稿，保留人工审核和提交确认，不自动投递 |
| P2-03 | 申请跟踪与结果回写 | 将 `job_search_tracker.csv`、`/outcome` 和面试准备状态做只读/受控编辑界面 |
| P2-04 | 企业官网与 ATS 来源 | Greenhouse、Lever、Workday 及国内企业 ATS；每个来源独立技能、fixture、契约测试和低频验证 |
| P2-05 | Windows 安装包 | 将 Python/Bun/CLI 检查、启动服务、浏览器打开和升级提示封装为安装包 |
| P2-06 | 通知与任务历史 | 本地通知、历史运行记录、失败重试和导出报告 |
| P2-07 | 云同步（可选） | 默认不做；若实施，需另立项设计加密、授权、数据删除和多设备冲突处理 |

## 5. 明确不开发的能力

- 验证码绕过、登录绕过、Cookie/密码窃取或自动读取浏览器凭证。
- 自动批量投递、自动私聊、自动代用户提交高风险申请。
- 未经确认将简历或职位正文上传到外部 AI 服务。
- 未经单独授权的云端多租户存储和默认云同步。

## 6. 推荐开发顺序

```text
P0-01 候选人配置
  → P0-02 智联端到端
  → P0-03 BOSS/51job 样本
  → P0-04 猎聘授权验证
  → P0-05 OpenAI 真实验证
  → P1-01/P1-02 Web 搜索
  → P1-03/P1-04 Web 排名任务
  → P1-05/P1-06 结果详情与持久化
  → P1-07/P1-08 简历整合与 PDF/Word
  → P1-10/P1-11 输入产品化
  → P1-12/P1-16 稳定性与新手验收
  → P2 浏览器、申请跟踪、安装包和新来源
```

## 7. 下一开发批次

建议下一批聚焦真实验收和收口：

1. **P0-01 至 P0-05**：使用真实候选人资料、平台样本和兼容 API 完成低频验收。
2. **P1-07/P1-08**：确认正式资料映射结果，补充 PDF 解析依赖和更多真实简历样本。
3. **P1-04/P1-12/P1-13**：补任务重启恢复、兼容服务探测、费用提示和更细的限流策略。

P0 的真实平台验证可以与 P1 并行，但在用户未提供候选人资料、授权或 API 配置前，只能保持“待验证”，不能将相关任务标记为完成。

## 1. 文档职责

本文件是国内招聘平台支持工作的开发计划、进度、验证、风险和决策台账。每次开发、测试、范围变更或外部平台状态变化后，都要更新本文件。

本文件不替代项目的 canonical workflow。职位评估、抓取安全边界和申请流程仍以 .claude/ 目录下的规范文件为准。

### 1.1 状态定义

| 状态 | 含义 |
|---|---|
| 未开始 | 尚未进行实现或调查 |
| 进行中 | 已开始，尚未满足验收条件 |
| 待验证 | 实现完成，等待测试或在线验证 |
| 已完成 | 交付物和验收标准全部满足 |
| 阻塞 | 依赖外部条件，当前无法继续 |
| 延期 | 明确推迟到后续版本 |
| 取消 | 经决策不再实施 |

### 1.2 更新规则

- 每次任务状态变化都更新任务总表和进度日志。
- 状态改为“已完成”时，必须填写验证命令、日期和结果。
- 状态改为“阻塞”时，必须填写阻塞原因、影响范围和解除条件。
- 新增任务使用新的编号，不复用已关闭编号。
- 平台协议、访问方式或字段变化写入决策与变更记录。
- 在线验证只记录低频、少量、可解释的请求，不纳入常规 CI。

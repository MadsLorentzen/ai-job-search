# Web 工作台界面现代化记录

**日期：** 2026-09-02  
**范围：** `webapp/static/index.html`、`webapp/static/styles.css`、`webapp/static/app.js`

## 本轮目标

解决旧版页面“所有表单纵向堆叠、关键动作不突出、滚动后不知道当前模块”的问题。接口、字段、隐私边界和 CLI 工作流保持不变。

## 已落地

- 增加四个工作区：概览、找职位、匹配结果、我的资料。
- 默认进入概览；切换工作区时隐藏无关模块，减少长页面滚动和认知负担。
- 侧栏导航、快捷入口和工作区标签统一联动；点击锚点会自动切换到对应工作区。
- 使用 `IntersectionObserver` 根据滚动位置更新当前侧栏高亮。
- 重做视觉基础：深色导航、浅色工作区、蓝色主动作、琥珀色强调，统一边框、阴影、圆角和状态色。
- 增大输入框、按钮和复选框的可点击区域；补充键盘焦点样式。
- 桌面端保留双栏工作区；移动端改为横向工作区标签和单栏内容，避免横向溢出。

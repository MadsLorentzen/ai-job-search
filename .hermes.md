# Hermes runtime pointer — ai-job-search

This is a thin pointer. The canonical specifications live elsewhere; this file
only tells a Hermes session where they are and what never to do.

## Routing

- `/rank` means: execute `.claude/commands/rank.md` exactly as written.
- `/apply` means: execute `.claude/commands/apply.md` exactly as written.
- `/scrape`, `/outcome`, `/interview`, `/upskill` likewise map to their
  `.claude/commands/<name>.md` files. Never reconstruct one of these
  workflows from memory or from another chat's summary — read the file.

## Hard limits (from rank.md and apply.md — restated here because they were violated)

- `/rank` defaults to **10 jobs per run** (`--limit` in rank.md Step 0). Do
  not expand the batch beyond what the user asked for. A larger backlog is
  handled by re-running `/rank`, which continues from deferred entries.
- Never load `job_scraper/seen_jobs.json` into context. Use
  `tools/rank_state.py candidates` / `sweep` / `apply` / `shortlist` — the
  state file moves through the tool, not the conversation.
- The apply-ready queue after a rank run is
  `python3 tools/rank_state.py shortlist --top N --json` — ranked, live,
  untracked jobs with `apply_status` and `stale_profile` flags. Never present
  the scraper's `fit` field as a score; only `rank_score`/`rank_verdict`
  count.
- If `01-candidate-profile.md` changes mid-run (an updated CV arrives),
  already-dispatched scoring agents' results are **stale**: rerun them with
  the new profile (or mark their output invalid via the profile-hash check —
  `shortlist` flags `stale_profile: true`). Never hand-patch stale scores.
- Cap subagent output: a scoring agent returning ≤5 job scores needs roughly
  **4–8k output tokens**, not 128k. Size max_tokens to the deliverable; on an
  OpenRouter HTTP 402, retry with a lower cap rather than failing the run.

## Private data

Never write personal candidate facts into the public repository. Form-ready
personal data lives only in the private workspace (see apply.md's standing
write-back rule and the private profile file it names).
